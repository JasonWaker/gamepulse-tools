# GamePulse Tools 交付说明 · v0.2.0

正式网址：[GitHub Pages](https://jasonwaker.github.io/gamepulse-tools/)
代码仓库：[JasonWaker/gamepulse-tools](https://github.com/JasonWaker/gamepulse-tools)

## 本版改进

- 改为固定侧栏、全局资料搜索、图片专题和快捷工具入口；手机侧栏可以展开与收起。
- WARDOGS 收录 7 把武器与 3 项装备；3 套原创起始配装可以直接载入。点击装备替换槽位，弹药数量、折扣、剩余预算与可重复购买次数实时计算。
- 武器详情连接配装和对比；最多三把武器比较价格、伤害、射速、射程、弹速和精度，并生成随目标血量变化的 TTK 图表。
- Aniimo 收录 24 条官方索引资料，可按属性筛选、搜索、收藏、加入四格个人规划队伍，展示属性与定位种类。属性图标明确标注为原创元素徽章，不冒充游戏角色图片。
- Agartha 提供个人目标完成度、训练检查点与历史图表，以及基于实测速率的时间估算。
- 五个工具统一支持本地自动草稿、命名保存、URL 分享恢复；“我的工具箱”汇总已保存方案、收藏和最近使用。
- 页面图片使用 Team17 官方新闻素材、Roblox 官方外链缩略图、原创装备插画和幻想场景。来源与使用依据在网站 About 页面及 `docs/MEDIA-v0.2.md`。

## 验证

- lint、TypeScript、计算测试和数据库 RLS 测试。
- 69 个导出 HTML 页面及内部引用审查。
- 浏览器覆盖装备预算、收藏、跨工具跳转、分享恢复、队伍限制、检查点和时间估算。

- 结果和截图：`docs/verification/v0.2.0`。

## 数据边界

WARDOGS 数值来自社区 Closed Alpha/Beta 记录，已标注来源与日期，不能当作正式发售后的已确认数值。配装不含未收录附件或物资。Aniimo 四格是个人规划布局，不宣称实际游戏队伍上限或未验证的克制规则。Agartha 使用用户自己的观测数据，不编造游戏 Pass 效果、价格或兑换码。

GitHub Pages 为静态站点。本地草稿和收藏保存在浏览器，不是账号云同步。数据库 schema/seed 和只读 RLS 保留供将来接入；本次没有部署外部数据库。没有发送推广消息或购买广告。

每次发布继续增加版本号，更新 CHANGELOG、Git tag 和 GitHub Release。

## v0.3.0 增量交付

- WARDOGS 共 13 件武器、3 件装备、3 辆载具，预算工具新增第六个载具槽位。
- 按补买次数预留预算，支持锁定、同类限制、主武器最低射程、车辆最低座位数；推荐按最少替换或最低价格排序，不声称战斗强度最优。
- 推荐可预览、应用和撤销；低价替代展示伤害/射程或座位变化。弹药数量按槽位继承，价格按替换武器重新计算。
- 官方简介列出的 4 个 Agartha 兑换码可复制，但没有实测兑换，失效日期未知。
- 增加数据覆盖说明及按需来源核查流程。检查生成候选差异，不自动改线上数据；装备防具和 Aniimo 仍需单独人工检查。
- 本轮：15 项单元/数据/RLS 测试通过，44 组响应式页面检查通过，7 页无障碍扫描零违规；新增预算、载具分享恢复、兑换码复制流程通过。
- 仍未提供完整附件、弹种、护甲弹道模型、官方配队协同规则或自动实时热度监测。
