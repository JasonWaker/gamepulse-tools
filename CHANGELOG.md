# Changelog

Every published update gets a new semantic version, annotated Git tag and GitHub release.

## 0.2.0 — 2026-09-07

GamePulse Tools v0.2.0 replaces the abstract landing page and manual-entry planners with a game workspace built around images, sourced records, and connected tools.

- Persistent game navigation, searchable catalog, responsive layouts and My toolkit.
- Seven WARDOGS weapons, three equipment records and three original starter builds. Click to equip; budget, standard ammunition, recruit discount, remaining cash and rebuys update instantly.
- Weapon details and three-way comparison with health-dependent TTK charts.
- Twenty-four official Aniimo index records with elemental and role filters, team composition, capacity checks and favorites.
- Personal progress checkpoints, session history and a visual boost/time calculator.
- Named saves, automatic local drafts, favorites, recent tools and shareable plans across all five tools.
- Official WARDOGS press imagery, external Roblox thumbnail, original equipment/element/adventure illustrations with sources and usage notes.

Community WARDOGS figures are labeled Closed Alpha/Beta and may change at launch. Aniimo images are elemental emblems, not official character portraits. Four roster slots are for personal planning.

Website: https://jasonwaker.github.io/gamepulse-tools/


## 0.1.0 — 2026-09-07

- Launch an independent English companion network for WARDOGS, Aniimo and Agartha Mog or Die.
- Add original tactical, orbital and geometric themes with responsive desktop/mobile layouts.
- Add five personal-input tools, local saves, shareable plans, equipment drawer and global search.
- Add eight source-backed Aniimo names; withhold unverified game statistics and codes.
- Add reusable registry-driven routes, source-aware records, SEO metadata and structured data.
- Add media rights gating, official-media discovery providers and a loopback-only review tool.
- Add Supabase-ready schema, source seed and tested anonymous RLS boundaries.
- Add automated versioned GitHub Pages publication and portable Cloudflare configuration.
- No production Supabase connection, ad network, official media rehosting or fabricated game data.
